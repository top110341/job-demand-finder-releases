# Job Demand Finder — ดาวน์โหลด

แอพค้นหาบริษัทที่กำลังรับคนไอที จากเว็บหางานหลักของไทย

**ดาวน์โหลดตัวติดตั้งล่าสุด:** [Releases → Latest](https://github.com/top110341/job-demand-finder-releases/releases/latest) → ไฟล์ `Job-Demand-Finder-x.y.z-setup.exe`

- Windows จะขึ้นเตือน SmartScreen (ตัวติดตั้งยังไม่ได้เซ็นรับรอง) — กด **More info → Run anyway**
- ติดตั้งครั้งเดียว หลังจากนั้นแอพจะอัปเดตเวอร์ชันใหม่ให้เองอัตโนมัติ

repo นี้เก็บเฉพาะไฟล์ติดตั้งและไฟล์สำหรับระบบอัปเดต
